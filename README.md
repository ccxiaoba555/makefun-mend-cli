mend — one patch tool for every AI edit format. It applies unified diffs (with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON tool-call edits to a tree of files, matching lines at three tiers (exact, trailing-whitespace-insensitive, fully-trimmed), and writes every change or none. Practice score 1000/1000 on the kit's 100 public checks.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
